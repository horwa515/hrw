PPT Format Converter V1.1 — Java 8 公司环境版

两个安装 ZIP 的解压密码均为：3609。
适用公司现有 Windows 10 x64 / Java 8（含 1.8.0_201），不需要安装新 Java 或设置 JAVA_HOME。

1. 完整解压 ZIP，输入密码 3609。
2. 打开文件夹，双击 Start.cmd，保持程序窗口打开。
3. 浏览器出现中文页面；如果没有自动打开，把窗口里的本机地址复制到 Edge。
4. 选择多个 .pptx，点击“开始转换”，下载结果。
5. 下载完成再关闭程序窗口。原文件不覆盖。

两版共有功能：
- 4:3（约 1.3333）及公司常见 1.4444 比例都转换为 16:9（约 1.7778）。两类分别允许 0.5% 的相对误差。
- 高度、图片和形状尺寸不变，原有内容水平居中。其他比例不改尺寸，仍调整字体。
- 可编辑中文设为黑体（SimHei）；英文仅将微软雅黑 / Microsoft YaHei 改为 Arial，其他英文字体保留。
- 中英文混排会按文字分别设置字体，保留字号、颜色、粗斜体和超链接。
- 图表、表格、母版、动画、图片等原始结构尽量保留；输出仍可编辑。

基础版（Basic）：
- 保持小体积，不包含 Office 加密库。
- 输入有 PPT 打开密码时，请先手动去掉密码。
- 输出不带 PPT 打开密码；需要时请在 PowerPoint 中手动设置 3609。

增强版（Enhanced）：
- 自动用 3609 打开有密码的 PPTX；输入无密码也可以转换。
- 所有成功输出的 PPTX 自动设置“打开密码”3609，包括原本没有密码的输入。
- 密码不为 3609 的文件会单独失败，不影响其他文件，也不修改原文件。
- 处理的是标准 Office PPTX 打开密码，不处理旧 .ppt、企业权限/IRM 或特殊访问控制。
- ZIP 的解压密码与 PPT 的打开密码是两层独立的密码，两者此处都设为 3609。

字体与兼容性：
- 需要目标电脑已安装黑体（SimHei），字体变化可能导致换行变化。
- 图片中烧录的中文不进行 OCR；嵌入 Excel/OLE 内部文字不改写，保持对象原始数据。
- 背景填充、运动路径动画、高级对象建议在 PowerPoint 中复查。
- 数字签名和 Strict OOXML 需先另存为普通无签名 PPTX。
- 已在真实 Java 8 环境验证两版、密码流程和独立加密工具互通；Windows PowerPoint 的实际排版和打开效果仍需在公司电脑检查。

示例：sample-company-1.4444.pptx 验证公司比例。
增强版另带 sample-company-3609.pptx，打开密码为 3609，可直接上传验证自动去密与重新加密。
