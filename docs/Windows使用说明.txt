PPT Format Converter V1.0 — Windows 使用说明

1. 将 ZIP 完整解压到一个文件夹。
2. 进入 PPTFormatConverter 文件夹，双击 Start.cmd。
3. 浏览器将打开本机转换页面。若未打开，把程序窗口里的地址复制到浏览器。
4. 选择或拖入 .pptx 文件，点击“开始转换”。
5. 下载转换好的 PPTX 或整批 ZIP。原文件不会被覆盖。
6. 下载后用 PowerPoint 检查文本、图表、母版和动画。退出前务必下载结果。
7. 关闭程序窗口或按 Ctrl+C 退出。只关闭网页不会停止程序。

本包适用 Windows 10/11 x64，已自带 Java 运行时，不需要你配置环境。
运行和转换都可以断网进行，不需要 PowerPoint；编辑及检查 PPT 则需相应软件。
旧的 .ppt 不支持，请先另存为 .pptx。
非 4:3 文件不会改变页面尺寸，但仍替换指定字体。
加密、有数字签名或 Strict OOXML 文件请先另存为标准、无加密、无签名 .pptx。

字体提示：Arial 不覆盖全部中文，系统会回退到可用中文字体。
因此中文字宽及换行可能变化。背景填充和运动路径动画也建议人工复查。

若双击失败：检查是否完整解压且 runtime 文件夹存在；不要单独移动 Start.cmd。
结果存放于本次进程的临时目录，正常退出后会清理；请及时下载。
详细规则、开发构建和限制见 README.md。
